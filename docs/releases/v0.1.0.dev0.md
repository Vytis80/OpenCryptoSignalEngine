# OpenCryptoSignalEngine v0.1.0.dev0

Prepared notes for the first public development prerelease of OpenCryptoSignalEngine. **The GitHub Release has not yet been published.**

## Repository snapshot

- **Bybit Scanner V2.6 `2.6.0-rc2`** — active multi-timeframe scanner and signal core.
- **Bybit Demo AutoTrader `1.5.4`** — demo-only execution component.
- **Bybit Scanner V2.5 `2.5.1`** — comparison baseline, with an explicit TP-ladder safety hotfix documented after LIVE validation.
- **Shared risk lifecycle** — deterministic initial protection, TP1 → breakeven, TP2 → TP1 and monotonic stop protection.

- **Bridge protocol v1** — shared deterministic payload normalization plus timestamped HMAC-SHA256 authentication between scanners and the Demo AutoTrader.
- **Public AI sidecar source** — the original observation-only GPT-OSS AI Judge implementation imported on 2026-09-09.

## Source-parity release blocker

The exact current V2 Blind LIVE source has **not yet been imported from a fresh sanitized deployment snapshot**. Therefore this prerelease must not be described as byte-for-byte identical to the latest LIVE AI implementation.

Before publishing the GitHub release, either:

1. import and validate the current sanitized V2 Blind source, then rerun CI/secret scan/release readiness; or
2. intentionally publish the repository snapshot as-is and state clearly that the documented V2 Blind LIVE research contract is newer than the included public AI source.

No release should silently imply parity that has not been verified.

## V2.5 TP-ladder safety finding

LIVE root-cause analysis found that independently obstacle-capped targets could become non-monotonic. The required final ladder is:

- LONG: `entry < TP1 < TP2 < TP3`
- SHORT: `entry > TP1 > TP2 > TP3`

Malformed ladders must not become `EXECUTE`. Runtime outbox cleanup data is not part of the repository.

## Reliability and safety

The repository includes component-specific offline tests, Python 3.11–3.13 shared-package CI, V2.5 regression coverage, a dedicated secret scan, and a release-readiness gate that rejects tracked runtime/secret artifacts and validates package/component version consistency.

Operational `.env` files, API credentials, Discord credentials, Groq/provider keys, bridge secrets, account-specific databases, AI response databases, logs, trade history and private deployment details are intentionally excluded.

## Python package artifacts

The wheel and source distribution represent the reusable package under `src/open_crypto_signal_engine/`. The wheel contains shared risk, protocol and backtesting libraries; it does **not** bundle the runnable Scanner V2.6, Demo AutoTrader or V2.5 applications.

## Development status

This is prerelease software. Scanner V2.6 remains a release candidate and the AutoTrader remains restricted to Bybit Demo Trading in the public project. Offline replay, AI observations and research statistics are software-validation tools, not guarantees of trading performance.

Use only your own local credentials in ignored runtime configuration. Never commit real Bybit, Discord, Groq/provider, bridge, SSH or cloud credentials.
