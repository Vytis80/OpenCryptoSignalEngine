# Code of Conduct

## Our standard

OpenCryptoSignalEngine aims to provide a constructive, technically focused and welcoming environment for contributors and users.

Participants are expected to:

- Be respectful and professional
- Discuss ideas and code rather than attacking people
- Give actionable technical feedback
- Respect privacy and never expose credentials, account data or other sensitive information
- Avoid spam, harassment, discrimination and intentionally disruptive behavior

## Unacceptable behavior

The following are not acceptable in project spaces:

- Harassment, threats or personal attacks
- Discriminatory or demeaning language
- Publishing another person's private information without permission
- Sharing API keys, tokens, private trading data or credentials
- Deliberately misleading security or trading claims
- Spam or repeated off-topic promotion

## Enforcement

Project maintainers may edit, remove or reject comments, commits, issues, pull requests and other contributions that violate these standards. Serious or repeated violations may result in temporary or permanent exclusion from project spaces.

## Reporting

For ordinary conduct concerns, contact the maintainer without posting sensitive personal information publicly. Security vulnerabilities should be handled according to [SECURITY.md](SECURITY.md).
